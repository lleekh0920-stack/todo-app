# 브라우저에 URL 입력 시 흐름
1. 브라우저가 DNS에 도메인의 IP 주소를 물어봄
2. 그 IP서버와 TCP 연결 (HTTPS면 TLS암호화 협상 추가)
3. HTTP 요청 전송
4. 서버가 처리후 HTTP 응답(HTML)
5. 브라우저가 HTML을 읽고 CSS,js,이미지를 추가 요청한 뒤 화면 렌더링
